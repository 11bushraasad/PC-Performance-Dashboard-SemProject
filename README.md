# PC Performance Dashboard

## About the project

We are making a dashboard that will show basic performance information from a computer in one place. Our current plan is to display CPU usage, memory usage, and disk usage.

This is a student project for our Software Construction and Development course. We are still deciding which operating system and programming tools to use, so some details may change as we work on it.

## Current status

We are at the planning stage. The initial requirements and project roles are being reviewed. The operating system, application type, refresh interval, and programming tools still need to be confirmed.

## Planned first features

- Show CPU usage.
- Show memory usage.
- Show disk usage.
- Refresh the readings while the dashboard is open.
- Show a message if a reading is unavailable.

These are our current plans and may change as we develop the project.
